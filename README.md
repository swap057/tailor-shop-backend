# ✂️ Tailor Shop Management System

A modern, full-stack web application designed to help tailor shops digitally manage customer measurements, track order statuses, and streamline daily operations. 

## 🚀 Tech Stack
* [cite_start]**Frontend:** React.js [cite: 1023]
* [cite_start]**Backend:** Java / Spring Boot 17 [cite: 1023, 1855]
* [cite_start]**Database:** MySQL (Hosted on Aiven) [cite: 1023, 1028]
* [cite_start]**Deployment:** Docker & Render (Backend) [cite: 1845, 1855]

## ✨ Key Features
* [cite_start]**Customer Management:** Add and store detailed customer profiles and contact information[cite: 1048].
* [cite_start]**Order Tracking:** Manage pending and completed orders for both shirts and pants[cite: 1048, 1516, 1518].
* [cite_start]**Detailed Measurements:** Store highly specific tailoring measurements (chest, waist, sleeves, collar, etc.) dynamically[cite: 1516, 1518].
* [cite_start]**Cloud-Ready:** Fully containerized with Docker and configured for live cloud database integration[cite: 1855, 1861].
